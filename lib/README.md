# ACV Playable Typography Libraries

This folder contains references and utilities for physics engines (Matter.js) and 2D canvas/rendering frameworks (p5.js).

The project uses ES modules configured through Vite:
- `matter-js`: Installed via npm (`npm install matter-js`) and accessible via `import Matter from 'matter-js'` or CDN fallback.
- `p5`: Installed via npm (`npm install p5`) and available for sketch instances.
